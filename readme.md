# 🎨 Pro Filter Studio

Pro Filter Studio is a browser-based image editing application built using HTML5, CSS3, JavaScript, and the Canvas API. It allows users to apply real-time image adjustments, artistic effects, and image processing filters directly in the browser without requiring any external software.

## 🚀 Live Demo

[View Live Project](https://pro-filter-studio.vercel.app)


## ✨ Features

- 📂 Upload images from your device
- ☀️ Adjust Brightness
- 🎚️ Adjust Contrast
- 🌈 Adjust Saturation
- ⚫ Grayscale Filter
- 🟤 Sepia Filter
- 🔄 Invert Colors
- 📸 Vintage Effect
- 🌫️ Gaussian Blur
- 🔍 Sharpen Filter
- 🖼️ Emboss Effect
- ✨ Edge Detection
- ↩️ Undo / Redo Support
- 💾 Export edited images as PNG
- 📱 Responsive User Interface
